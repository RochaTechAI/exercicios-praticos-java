# ☕ Java 17 - Exercícios Práticos & Algoritmos

[![Java 17](https://img.shields.io/badge/Java-17-orange.svg)](https://www.oracle.com/java/technologies/downloads/#java17)
[![Maven](https://img.shields.io/badge/Maven-4.0-blue.svg)](https://maven.apache.org/)
[![JUnit 5](https://img.shields.io/badge/JUnit-5-green.svg)](https://junit.org/junit5/)

Repositório dedicado à prática contínua de programação em **Java 17**, focado no fortalecimento de fundamentos, estruturas de dados, Orientação a Objetos (POO), concorrência e recursos modernos da linguagem.

Os exercícios são estruturados utilizando **TDD (Test-Driven Development)** e validados através de testes unitários com **JUnit 5**.

---

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Java 17 (LTS)
- **Gerenciador de Dependências:** Apache Maven
- **Testes Unitários:** JUnit 5 (Jupiter)
- **IDE:** IntelliJ IDEA
- **Ambiente OS:** Windows / Ubuntu

---

Como Executar o Projeto
Pré-requisitos
JDK 17 instalado e configurado nas variáveis de ambiente.

Git instalado.

Passo a passo

Clonar o repositório:
git clone [https://github.com/seu-usuario/exercicios-praticos-java.git]

Acessar a pasta do projeto:
cd exercicios-praticos-java

Executar todos os testes via Maven:
mvn test
